Core Functionality

This unit uses non-contact ultrasonic waves to detect the exact liquid levels in your tank. An intelligent automation controller monitors custom low and high thresholds, automatically switching a relay to manage the water pump. You get instant local alerts via a built-in buzzer and online visibility on a live web dashboard.

Technical Capabilities
💧

Precision Sensor Reading

Uses non-contact HC-SR04 sonic distance ranging for exact height calculations, unaffected by water impurities.

⚙️

Custom Control Thresholds

Define exact start and stop percentages inside the code to manage pump activation and shut-off cycles.

🔔

Local Alarm System

A secondary physical buzzer sounds immediately if critical overflow or underflow boundaries are breached.

🌐

Web UI & REST Interface

Transmits data packets over local Wi-Fi networks to sync a mobile-friendly dashboard in real-time.

Operational Workflow
1
Measurement
Sensor fires sound pulse and measures echo bounce-back time.
→
2
Computation
NodeMCU translates the delay to distance and level percentage.
→
3
Decision
Relay turns pump ON if <20% and OFF when level reaches >90%.
→
4
Telemetry
Sensor metrics package is posted over HTTP to the backend server.
→
5
User Portal
Status dashboard renders live statistics on your phone or PC screen.
