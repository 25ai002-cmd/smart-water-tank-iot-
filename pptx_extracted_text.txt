Why Python Helps Beginners Presenter: Nayan Barot Roll No: 25AI027 | St Xavier's College MENTAL LOAD HYPOTHESIS C forces beginners to think about computer hardware and code logic at the same time. This creates high mental fatigue. Python hides computer hardware details, letting students focus on basic logic alone. EASY TO READ Python looks like plain English, making it easy to translate thoughts into lines of code. COURSE ORDER RECOMMENDATION Schools should teach coding logic in Python first, and teach C memory management in later semesters.

The First Coding Class Dilemma Presenter: Tanvi Patel Roll No: 25AI056 | St Xavier's College C Language (Traditional Approach) •  Hardware Focus : Directly exposes memory allocation, pointers, and CPU-level execution. •  Steep Learning Curve : Complex compiler rules, strict syntax (semicolons, braces), and cryptic error messages. •  Cognitive Load : Novice students waste significant time debugging syntax rather than learning computational thinking. Python Language (Modern Alternative) •  Logic First : Minimalist syntax lets students focus immediately on algorithm design and logic flow. •  High-Level Abstraction : Hides pointer arithmetic and memory management, reducing early frustration. •  Rapid Feedback : Interactive execution (REPL) and simple run cycle enable faster iteration and learning.
=== slide5.xml ===
What Previous Studies Missed Presenter: Tanvi Patel Roll No: 25AI056 | St Xavier's College FLAWS IN PAST RESEARCH •  Student Mix-up : Mixed computer science majors with other fields, making tests unfair. •  Different Teachers : Grades were affected by different teachers, not just the coding language. •  Different Exams : Exam questions were not identical between compared languages. HOW THIS EXPERIMENT FIXED IT •  Same Teachers : The exact same three teachers taught both groups. •  Same Topics : Classes covered identical programming topics (loops, arrays, logic). •  Large Group : Tested 391 students under strict rules to ensure fair data.

The Course Setup: MC102 Presenter: Tanvi Patel Roll No: 25AI056 | St Xavier's College INSTITUTIONAL CONTEXT •  Top Tier University : Conducted at UNICAMP, one of Brazil's and Latin America's top-tier research institutions. •  Core Curriculum : A mandatory introductory programming course (MC102) for all science and engineering majors. •  Large-Scale Enrollment : Over 800 students enroll per semester, across morning, afternoon, and evening sections. GRADING & LOGISTICS •  Grade Weighting : Grading is split into 80% written exams (conducted on paper) and 20% online coding labs. •  Exam Standard : Written midterms and finals test logical logic flow rather than syntax memory. •  Course Periods : Morning (Physics and Math), Afternoon (Statistics), and Evening (Food Engineering) sections.

How the Experiment Was Built Presenter: Barot Yaksh Roll No: 25AI002 | St Xavier's College CLASS SPLIT 391 college students split over two semesters (194 in Python, 197 in C). LANGUAGE SWAP Semester 1 (2015) used C / Python. Semester 2 (2016) swapped them for the same majors. SAME LESSONS Both groups covered variables, loops, arrays, and sorting logic. SAME TEACHERS The same three professors (JW, HH, DA) taught both semesters to ensure fairness.
=== slide9.xml ===
Ensuring a Fair Comparison Presenter: Barot Yaksh Roll No: 25AI002 | St Xavier's College SAME TEACHERS The same professors lectured in both semesters. This stopped differences in teaching style from changing results. SAME CURRICULUM The difficulty and sequence of lessons were exactly matched. No extra topics were added or removed. SAME EXAMS Automated computer grading was used for homework. Written exams tested logic instead of syntax memory.
