🛠️ Components Used

NodeMCU ESP8266 An open-source Wi-Fi IoT development board. Measures echo durations and reports them to the server.
HC-SR04 Sensor Ultrasonic transmitter and receiver modules. Measures distance to the water level without contact.
5V Relay Module Electromechanical switch that allows the low-voltage NodeMCU to trigger the high-current water pump.
Active Buzzer (5V) Sound alert module. Emits a high-frequency alarm sound if water is low or high to warn users locally.
Mini DC Pump A 5V submersible water pump. Serves as the demonstration motor for the auto-fill and manual actions.
Breadboard & Wires Solderless breadboard and jumper wires for connecting components safely and cleanly.

🌐 API Endpoints Reference

The system is powered by a REST API. You can read Swagger API documentation at http://localhost:3000/api-docs.

GET /api/statusGets full system status (water level, settings, motor, buzzer state).
GET /api/sensorGets the latest raw sensor distance and calculated water percentage.
POST /api/sensorSent by NodeMCU: payload {"distance": 12.5} to update reading.
GET /api/settingsGets current start/stop thresholds, schedule config.
POST /api/settingsUpdates threshold settings (e.g. startThreshold, stopThreshold).
POST /api/motorTriggers motor manual state: payload {"motorOn": true/false}.
GET /api/historyGets historical sensor log data (supports ?limit=50 parameter).
DELETE /api/historyClears all historical records in database.
POST /api/subscribeRegisters a new browser push notification subscription.
